# Marital Bliss Academy

A responsive React and Vite website for Marital Bliss Academy, a marriage counseling and relationship wellness brand.

## Features

- Responsive landing page sections for hero, services, about, testimonials, and contact
- Mobile-friendly navigation
- Branded favicon and browser title
- Tailwind CSS styling
- Reusable lightweight UI components

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React icons

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
